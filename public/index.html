CDC Detailing quote card

Unofficial demo built from the public website of CDC Detailing LLC (Pitman, NJ) for an Agentplace agent. Prices are the shop's published "starting at" figures; availability is a demo schedule.

API

  • GET /api/services: catalog, add-ons, policies
  • GET /api/quote?service=ceramic-5&vehicle=suv&…&mobile=true&zip=08033
  • GET /api/availability?service=interior&days=7

Embed

<script src="https://<this-host>/cdc-quote-card.js"></script>
<cdc-quote-card api="https://<this-host>" vehicle="suv" goal="protect"></cdc-quote-card>
